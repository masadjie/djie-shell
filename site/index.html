Port forwarding · Proxy · Snippets

Tunnel & perintah favorit,
sekali klik.

Port Forwarding

Buka database di server lewat localhost, ekspos port lokal ke server, atau jadikan server proxy SOCKS. Nyalakan dengan toggle, status terlihat langsung.

Proxy SOCKS5 & HTTP

Di jaringan kantor atau kampus yang wajib lewat proxy? Atur proxy per host, lengkap dengan login. Terminal, SFTP, tunnel, dan koneksi database ikut lewat proxy — password proxy tersimpan terenkripsi di vault.

Keamanan & sync

Kuncinya cuma
kamu yang pegang.

Tidak ada akun Djie Shell dan tidak ada server kami. Vault terenkripsi di perangkatmu, dan salinannya disimpan di folder tersembunyi Google Drive milikmu.

Enkripsi end-to-end

Argon2id + XChaCha20-Poly1305. Master password tidak pernah disimpan atau dikirim ke mana pun.

Sync Google Drive

Otomatis setelah setiap perubahan. Login di Mac atau PC lain, masukkan master password, semua host kembali.

Touch ID & Windows Hello

Buka vault dengan sidik jari atau wajah. Kunci kapan saja dengan ⇧⌘L di Mac atau Ctrl+Shift+L di Windows.

Install

Download. Buka. Connect.

Gratis selamanya, tanpa iklan. Kalau ada masalah atau ide fitur, ceritakan lewat GitHub.

Cara install di Mac

  1. Download file .dmg, buka, lalu seret Djie Shell ke folder Applications.
  2. App belum dinotarisasi Apple (butuh akun developer berbayar). Saat pertama dibuka, buka System Settings → Privacy & Security lalu klik Open Anyway.
  3. Kalau muncul pesan "rusak", jalankan sekali di Terminal:
xattr -cr "/Applications/Djie Shell.app"

Cara install di Windows

  1. Download Setup.exe: versi x64 untuk kebanyakan PC, atau ARM64 untuk PC ARM seperti Snapdragon.
  2. App belum ditandatangani sertifikat berbayar. Kalau muncul Windows protected your PC, klik More info → Run anyway.
  3. Ikuti installer — tidak butuh hak admin. Setelah selesai, buka Djie Shell dari Start Menu.

Hapus kapan saja lewat Settings → Apps. Vault dan pengaturanmu tetap aman.

Cara install di Linux (beta)

  1. Download AppImage: x86_64 untuk kebanyakan PC, atau aarch64 untuk PC/laptop ARM.
  2. Jadikan bisa dijalankan, lalu buka (atau klik dua kali dari file manager):
chmod +x Djie-Shell-Linux-*.AppImage && ./Djie-Shell-Linux-*.AppImage

AppImage Linux hadir mulai rilis v0.5. Sementara itu, build dari source di GitHub (lihat README).

Butuh distro yang cukup baru (glibc 2.39+), mis. Ubuntu 24.04, Debian 13, Fedora 40. Versi beta: hosts, terminal SSH & lokal, keychain, dan snippet — fitur lain menyusul.

FAQ

Yang sering ditanyakan.

Benar-benar gratis?

Ya. Lisensi MIT, tanpa iklan dan tanpa langganan. Donasi sifatnya sukarela.

Apakah Djie Shell bisa melihat password server saya?

Tidak. Semua data dienkripsi di perangkatmu dengan master password. Djie Shell tidak punya server, dan Google hanya menyimpan file terenkripsi yang tidak bisa dibaca tanpa master password.

Kalau lupa master password?

Vault tidak bisa dibuka — itu konsekuensi enkripsi end-to-end. Simpan master password di tempat yang aman.

Kenapa muncul peringatan saat dibuka?

App belum dinotarisasi Apple dan belum ditandatangani sertifikat Windows, karena keduanya berbayar. Kode sumbernya terbuka di GitHub untuk diperiksa siapa saja. Di Mac buka lewat Privacy & Security → Open Anyway; di Windows klik More info → Run anyway. Cukup sekali.

Akses Google Drive apa yang diminta?

Hanya folder data khusus aplikasi (drive.appdata) yang tersembunyi. Djie Shell tidak bisa melihat file lain di Drive-mu.

Bisa konek lewat proxy kantor?

Bisa. Di editor host buka Lanjutan → Proxy, pilih SOCKS5 atau HTTP, isi alamat, port, dan login jika perlu. Bisa juga sebaliknya: jadikan server SSH sebagai proxy SOCKS lewat Port Forwarding.

Ada versi Windows?

Ada! Windows 10 dan 11, untuk PC x64 maupun ARM64. Memakai inti Rust yang sama, jadi satu vault bisa dipakai bersama di Mac dan Windows lewat sync Google Drive.

Ada bahasa Inggris?

Ada! Semua app tersedia dalam bahasa Indonesia dan Inggris — mengikuti bahasa sistem, atau pilih sendiri lewat menu Bahasa / Language. Pesan error dari server ikut diterjemahkan.

Ada versi Linux?

Ada, masih beta: AppImage untuk x86_64 dan ARM64 (GTK4 + libadwaita, terminal VTE). Sudah bisa kelola host, terminal SSH & lokal, keychain, dan snippet; SFTP, Database, Docker, Dashboard, dan sync Google menyusul.
